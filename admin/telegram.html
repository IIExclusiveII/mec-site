Сповіщення про заявки в Telegram

Після налаштування кожна заявка з сайту миттєво приходитиме вам у Telegram.

  1. У Telegram відкрийте @BotFather → надішліть /newbot → задайте назву. Він дасть токен виду 1234567890:AA....
  2. Відкрийте свого нового бота і напишіть йому будь-яке повідомлення (наприклад «привіт») — без цього бот не має права вам писати.
  3. У кабінеті Netlify: Site configuration → Environment variables → Add a variable. Додайте:
    TELEGRAM_BOT_TOKEN = ваш токен з BotFather

    TELEGRAM_CHAT_ID = ваш ID (дізнаєтесь кнопкою нижче)
  4. Після додавання змінних натисніть у Netlify Deploys → Trigger deploy → Deploy site (щоб зміни застосувались), потім поверніться сюди й натисніть «Перевірити».
