ГОТОВО ДЛЯ NETLIFY DROP

Цю папку можна перетягнути на Netlify як новий проект.

Що робити:
1. Відкрий https://app.netlify.com/drop
2. Перетягни всю папку NETLIFY_DROP_READY_MECUA у вікно Netlify.
3. Дочекайся публікації.
4. Перевір:
   https://mecua.netlify.app/
   https://mecua.netlify.app/sitemap.xml
   https://mecua.netlify.app/robots.txt
   https://mecua.netlify.app/elektromontazh-kyiv.html
   https://mecua.netlify.app/ru/

Важливо:
- index.html вже лежить у корені цієї папки.
- Build command не потрібен.
- Publish directory не потрібно вказувати для Netlify Drop.
- Якщо Netlify створить іншу адресу сайту, треба буде замінити mecua.netlify.app у SEO-файлах на нову адресу.
